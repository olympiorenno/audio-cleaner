# Como Contribuir

Obrigado pelo interesse! Toda contribuição é bem-vinda.

## Ideias de melhoria

- [ ] Interface gráfica (GUI) simples
- [ ] Instalador `.exe` para Windows (sem precisar do Python)
- [ ] Suporte a macOS e Linux
- [ ] Detecção automática de vícios (sem precisar configurar manualmente)
- [ ] Perfis por professor/palestrante
- [ ] Suporte a GPU AMD (ROCm)
- [ ] Integração direta com Zoom/Teams/Meet

## Como rodar localmente

```bash
git clone https://github.com/olympiorenno/audio-cleaner.git
cd audio-cleaner
pip install -r requirements.txt
python audio_cleaner.py
```

## Enviando contribuições

1. Faça um fork do repositório
2. Crie uma branch: `git checkout -b minha-melhoria`
3. Faça suas alterações e commit: `git commit -m "descrição clara"`
4. Envie: `git push origin minha-melhoria`
5. Abra um Pull Request

## Reportando bugs

Abra uma [Issue](https://github.com/olympiorenno/audio-cleaner/issues) com:
- O que aconteceu
- O que era esperado
- Mensagem de erro (se houver)
- Sistema operacional e versão do Python
